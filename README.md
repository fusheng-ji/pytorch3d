# PyTorch3D pull request evidence

This branch stores numerical results, figures, and reproduction scripts for
contributions from this fork. Each pull request has its own directory.

| Pull request | Evidence |
| --- | --- |
| [#2055: Fix duplicate indices in farthest point sampling](https://github.com/facebookresearch/pytorch3d/pull/2055) | [Numerical results, figure, and reproduction instructions](2055/README.md) |

branch. The results report correctness checks on the documented environment;
