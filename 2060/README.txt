Polygon clipping for box3d_overlap
==================================

Depends on:   https://github.com/facebookresearch/pytorch3d/pull/2059
Revisions:    main      88e182f

Environment:  Linux, Python 3.12.13, PyTorch 2.11.0+cu130, CUDA 13.0,

Accuracy
--------
cases.pt holds ten scenarios (make_cases.py, seed 1234): random rotated boxes
at sizes ~0.01, ~1 and ~100; grid-snapped axis-aligned boxes with shared
planes, also under a common rotation and at size ~0.01; random rotated boxes
where the diagonal pairs are identical, and the same with 1e-4 vertex noise;
and nested boxes sharing a corner.

capture_outputs.py runs one native build on every scenario on CPU and CUDA.
evaluate_exact.py compares main CPU, main CUDA, #2059 CUDA, this PR's CPU and
this PR's CUDA against float64 halfspace intersections (exact_volume.py,
scipy HalfspaceIntersection + ConvexHull) on the same pairs: 300 random pairs
per scenario plus every pair where any two implementations disagree by more
than 1e-4 in IoU. The metric is |IoU - exact IoU|.

- exact-comparison.csv: per scenario, the maximum error and the number of
  pairs with error above 1e-3 for each implementation.
- exact-pairs.csv: every checked pair with its exact volume and IoU and the
  IoU from each implementation.

Main and #2059 share the old algorithm and reach 0.25 IoU error on random
rotated boxes, and inf at size ~0.01 with shared planes (the absolute 1e-4
area threshold disables deduplication of coincident faces). This PR stays
below 6e-7 everywhere except the noisy boxes (3.5e-4, the noise level).

Reproduce
---------
Build the native extension at each revision. With MAIN_SO, PR2059_SO and
NEW_SO the built _C*.so files and this directory as cwd:

  python make_cases.py cases.pt          # optional; cases.pt is included
  python capture_outputs.py "$MAIN_SO"   cases.pt outputs-main.pt
  python capture_outputs.py "$PR2059_SO" cases.pt outputs-pr2059.pt
  python capture_outputs.py "$NEW_SO"    cases.pt outputs-new.pt
  python evaluate_exact.py cases.pt . base=outputs-main.pt \
      opt=outputs-pr2059.pt polycpu=outputs-new.pt
  python benchmark_native.py --extension "$NEW_SO" --device 0 \
      --fixture fixture1805.json --include-issue --output gpu-benchmark-new.json
  python cpu_benchmark.py "$NEW_SO" > cpu-benchmark-new.json
  python make_evidence.py

Limits
------
- One GPU model and one software stack; the full repository test suite was
  not rerun.
- Faces within dEpsilon (1e-3) of the face size are treated as one plane, so
  for such inputs the volume can differ from the exact one by up to about
  that fraction.
- The halfspace reference fits each face plane through its corners; for the
  noisy boxes it is only exact to the noise level.
- Local paths in logs are replaced with <checkout>, <python-env>, <path>.
